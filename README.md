Entrants send exactly one word, the word their ex would use to describe them, and nothing else. The funniest, most painfully honest word takes the whole reward.

This entry's program scores 10 fresh candidate words against the judge's published brief — in the brief's own criterion order — and writes the winner to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
